# Tools Used

## Challenge partner

1. **Exa** — powers the core company and people-research workflow.

## Tech partners

1. **Google Gemini** — AI candidate matching and scoring.
2. **Aiven for PostgreSQL** — managed PostgreSQL database for project data.
3. **Codex** — AI-assisted development and iteration.

## Project stack

1. **SolidJS + TypeScript** — reactive frontend application.
2. **FastAPI + Python** — high-performance backend API.
3. **Tailwind CSS** — utility-first interface styling.
4. **TanStack Query & Table** — API-state management and data-heavy views.
5. **Vite** — fast frontend builds and hot reload.
6. **Docker Compose** — reproducible local full-stack runtime.
7. **SQLAlchemy + Alembic** — database access and schema migrations.
8. **Uvicorn** — ASGI runtime server for FastAPI.
